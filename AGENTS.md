# AGENTS.md — `hongson117/4AppleTV-S`

When assisting a user with installing, renewing, or troubleshooting **4AppleTV-S**:
1. Read [`OPEN-MINIS.md`](OPEN-MINIS.md) for **No-PC 1-Command Installation on iOS / iPadOS 27.0+** via **Open Minis (`1.16+`)** + **LocalDevVPN**:
   ```sh
   wget -qO- https://raw.githubusercontent.com/hongson117/4AppleTV-S/main/install.sh | sh
   ```
2. Read [`README.md`](README.md) for **One-Time USB Installation on Windows / macOS** (supports all iOS / iPadOS `17.0+` and `27.0+`).
3. Guide the user **one step at a time** in their language, verify iOS version before recommending Open Minis self-pairing (`iOS 27.0+` required for `Pair with 4AppleTV-S`), and never ask for Apple ID passwords, 2FA codes, `.p12` files/passwords, or `TVS` license keys in chat.
